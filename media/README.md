# /media

This folder holds small static images (e.g. `welcome-poster.jpg`).

**Videos no longer live here.** They are uploaded through the password-protected
admin page and stored in Cloudflare R2, so there is no file-size limit.

➡️ To add or replace a video, go to **`yoursite.com/admin`** on your phone,
enter the password, pick a slot, and upload. See **`DEPLOY.md`** in the repo
root for the one-time Cloudflare setup.
