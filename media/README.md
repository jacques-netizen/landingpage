# Upload videos here — straight from your phone

No code needed. Record on your phone, then in the **GitHub app** (or
github.com → **Add file → Upload files**) drop the clip into this `/media`
folder using the **exact filename** below. Commit, wait ~1 minute, and the
site turns the player on automatically. Remove/replace a file the same way.

| Upload this filename | Shows up here on the site |
|----------------------|---------------------------|
| `faq-1.mp4` | FAQ answer: "What is content distribution and how does clipping work?" |
| `faq-2.mp4` | FAQ answer: "How is this different from paid ads?" |
| `faq-3.mp4` | FAQ answer: "How do you make sure the views are real, not bots?" |
| `walmart.mp4` | Walmart case-study clip (replaces the temporary Google Drive video) |

## Rules of thumb
- **Keep each file under 100MB** — that's GitHub's hard per-file limit. If a
  clip is bigger, trim it or compress it on your phone before uploading.
- **`.mp4` (H.264) plays everywhere.** If you upload `.mov` from an iPhone,
  it usually works too, but `.mp4` is the safe bet.
- Filenames are **case-sensitive** and must match exactly (all lowercase).
- Until a file exists, that player shows a tasteful "Filming soon" state, so
  the page never looks broken.
