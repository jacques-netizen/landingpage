Import from spreadsheet · the fast way

Paste a CSV (a copy from your tracker, or a Google Sheet). Columns are matched by name — include at least url and views. Optional: creator, platform, title, posted, thumb, featured, status (rejected/flagged rows are skipped). It fills the clips and recalculates totals; review below, then Save.

Automate it — no manual paste
Auto-sync from a Google Sheet (fully hands-off): keep a sheet with those columns → File → Share → Publish to web → CSV → copy the link → in Cloudflare set a Worker variable CAMPAIGN_CSV_URL to it. The dashboard then refreshes from the sheet every 15 minutes on its own. Fill the sheet however you like (paste from your tracker, or point a scraper/automation at it).

Push from a script or automation (Zapier, Make, cron): send the CSV as a POST to /api/campaign/import with header Authorization: Bearer <password>. Each push updates the live dashboard immediately.
